# Support

## Questions

Open an issue with your question until the repository enables Discussions.

## Bugs

Open an issue with the [bug report form](https://github.com/mateuscmtropical/cloudbot/issues/new/choose).
Include:

- The CloudBot version.
- The operating system of the server and how CloudBot was installed.
- Whether you connected Claude with a subscription or an API key.
- The steps you took, what you expected and what happened.
- Logs from `cloudbot logs`, with secrets removed.

## Security problems

Do not report security problems in an issue. Read the
[security policy](SECURITY.md) instead.
